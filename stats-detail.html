고객사별 분리 DB 기반 통계 집계 로직 개발

MySQL / 동적 UNION ALL / 클레임 통계 집계 / 데이터 후처리

고객사별로 DB가 분리된 멀티 테넌트 구조에서 연도별 클레임 건수와 사유를 통합 조회하고 집계하는 로직을 개발했습니다. 다수의 독립된 데이터베이스를 효율적으로 묶어 운영에 활용 가능한 통계 데이터를 생성하는 것이 핵심입니다.

데이터 정제

NULL값이나 빈값 등 예외 케이스를 처리하여 통계 데이터의 신뢰도 향상

Problem

문제 상황

시스템 구조상 고객사별로 별도의 데이터베이스를 사용하는 구조였기 때문에, 전체 고객사를 대상으로 하는 통합 통계를 추출하기 어려웠습니다. 특히 연도별 클레임 건수와 그 사유를 통합하여 운영팀이 대시보드에서 바로 확인할 수 있는 형태의 데이터가 필요했습니다.

Solution

해결 방식
  • 대상 고객사 목록을 먼저 조회한 뒤 고객사별 DB명을 동적으로 생성
  • 각 DB의 클레임 데이터를 조회하는 쿼리를 만들고 UNION ALL로 결합하는 동적 쿼리 생성 로직 구현
  • 연도별, 클레임 사유별 집계를 수행하고 PHP에서 최종 총계 및 요약 계산 로직 추가
  • 사유 없음(NULL/빈값) 케이스까지 예외 처리해 운영 화면 품질 개선

Technical Points

  • 멀티 테넌트에 가까운 분리 DB 구조에서 통합 통계를 제공하는 집계 로직 구현
  • 운영 화면에 바로 활용할 수 있도록 단순 조회가 아니라 요약·총계 형태로 후처리
  • PHP와 MySQL을 조합해 동적 쿼리 생성과 화면용 데이터 구조화를 동시에 처리

복잡한 분리 DB 구조를 통합하기 위해 사용된 SQL 구성 로직과 PHP 후처리 코드의 핵심 부분입니다.
