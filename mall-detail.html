My Role

주요 수행 내용
  • 기간별 / 조건별 검색, 정렬, 필터 기능이 포함된 관리자 화면 개발
  • 신규 고객사 수, 전체 고객사 수, 전체 회원 수 등 운영 지표 조회 로직 구현
  • 요일·시간대별 가입 패턴을 시각화하는 HeatMap 화면 개발
  • 계약만료 예정 업체, 테스트 종료 예정 업체, 연동 저하 업체를 빠르게 식별할 수 있는 모니터링 페이지 구성

Technical Points

  • 운영팀이 수작업 없이 상태를 파악할 수 있도록 내부 관리 기능을 데이터 기반으로 시각화
  • 표, 차트, HeatMap을 함께 사용해 운영 현황을 직관적으로 확인할 수 있게 구성
  • 계약 상태, 상품 등록, 주문 수집 등의 지표를 결합해 이상 징후를 빠르게 찾을 수 있도록 설계

실제 운영 중인 대시보드 화면들입니다. 고객사 현황부터 연동 상태까지 다양한 지표를 한눈에 확인할 수 있습니다.

Screens

고객사 현황 화면: 신규 회원 수, 신규 고객사 수, 전체 고객사 수를 기간별로 시각화
시간/요일별 가입 HeatMap: 가입 패턴을 시간대와 요일 기준으로 분석할 수 있도록 구현
계약만료 예정 업체 화면: 남은일수, 상품등록, 주문수집 현황을 함께 확인 가능
연동현황 체크 화면: 상품연동 및 주문건수의 전월·2달전·3달전 대비 증감률을 비교
테스트 만료 예정 업체 화면: 테스트 종료 예정 고객사를 남은일수 기준으로 관리
클라이언트 관리 화면: 고객사 정보 검색 및 관리 기능을 제공하는 내부 운영 페이지
